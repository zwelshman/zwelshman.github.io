# How to publish a blog post

Drop a markdown file into `_posts/`. Filename format is mandatory:

    YYYY-MM-DD-your-title.md

e.g. `2026-10-14-notes-on-sail-pipelines.md`

The file must start with frontmatter:

    ---
    title: "Your Post Title"
    date: 2026-10-14
    ---

Everything after that is plain markdown. The homepage lists all posts automatically.
